# Yearbook reviews

All design work stays on `design/yearbook-2020`; nothing is deployed.

[Iteration index](iterations.md) lists the saved PDFs and checkpoints. Each
iteration directory contains its PDF, full HTML prototype, image proofs and
content/layout audit. Earlier editions remain available for comparison.

Authoring sources, original photographs and licensed redesign fonts are in
`resources/design/yearbook/`. Build commands are documented in
`tools/yearbook/README.md`. These review files are not Laravel runtime assets.
