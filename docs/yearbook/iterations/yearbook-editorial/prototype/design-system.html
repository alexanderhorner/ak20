AK20 / EDITORIAL EDITIONDESIGN STUDY

Built for the page.

Grid
ISO A4, 210 × 297 mm. Outer margins: 38 pt (13.4 mm). Photo-led profile header, shared biographical rows and a consistent two-column reading structure.
Typography
Readable body text, dark field labels, manually fitted long surnames, and embedded fonts. Italics add warmth; fine rules establish the rhythm without heavy boxes.
Playfulness
A red full stop, a small year medallion, a restrained pen loop and colored childhood-photo mounts. Decorative marks stay clear of text and photographs.
Print
52 pages with exact A4 geometry and safe outer margins. The PDF retains selectable vector text and original PDF photo artwork, with the source resolution preserved.
Implementation
The real-content HTML prototype generates the PDF. Browser-measured positions place the original artwork. 1,135 matching text positions differ by less than one point.
Preservation
All 215 content units and 88 photo placements checked. The original PDF is attached unchanged. Version one remains intact. The authorized website update is ak20.alexanderhorner.de.
